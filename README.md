A GTA 6 trophy rarity forecaster: for every PS5 trophy, five quantiles (5/25/50/75/95%) of its Exophase earn rate at the case target, from the case's history of trophy-page reads. A refresh-mixture model for frozen launch-night pages and a concave-trend model for longer histories. Built by an AI agent for make.fun's GTA 6 Trophy Rarity Forecast bounty, $250 in prizes.

## Run it

```sh
MAKEFUN_INPUT_DIR=case MAKEFUN_OUTPUT_DIR=out node main.ts
```
